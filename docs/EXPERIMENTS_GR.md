# Πείραμα 1 — OLS έναντι ML και Υβριδικού (Classic + ML)

Ο καθηγητής ζήτησε πρώτα κλασική παλινδρόμηση και μετά νευρωνικό που θα μειώνει το μη εξηγούμενο σφάλμα της. Υλοποιούμε **έξι συγκρίσιμα μοντέλα**, με ίδιο δοκιμαστικό διάστημα: OLS, Ridge, LASSO, Elastic Net, ανεξάρτητο MLP (MSE loss), OLS + MLP προβλέψεων των ιστορικών residuals.

Για το tuning χρησιμοποιούμε Optuna / TPE (αριθμός νευρώνων, 1–2 hidden layers, learning rate, weight decay, batch size). Επιλέγουμε υπερπαραμέτρους μόνο με παλαιότερες, χρονικά διαχωρισμένες validation περιόδους. **Κανένα νευρωνικό δεν εκπαιδεύεται στα πραγματικά σφάλματα του μελλοντικού test**. Το υβριδικό χρησιμοποιεί μόνο residuals που προέκυψαν από προηγούμενες πραγματικά out-of-sample προβλέψεις OLS.

Το EPS Earnings Revisions παραμένει προαιρετικό 6ο χαρακτηριστικό και απαιτεί επικυρωμένες ιστορικές προβλέψεις αναλυτών. Μέχρι τότε, τα αποτελέσματα της παλιάς βάσης είναι μόνο με πέντε εισόδους. Καμία αναφορά σε «σίγουρο alpha» ή αποδεδειγμένα κέρδη.

**Εκτέλεση:**

```bash
pip install -r requirements.txt
python -m pytest -q
python run_experiments.py --trials 12 --rebalance-months 6
```

Τα reports θα εμφανιστούν στο `results/comparison/`. Δεν δημοσιεύουμε ιδιωτικά αρχεία δεδομένων ή αποτελέσματα αν δεν συνοδεύονται από τον περιορισμό του survivorship bias.
